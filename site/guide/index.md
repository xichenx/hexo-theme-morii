# 接入路线：做一个「小林的笔记」

第一次接触 Hexo？按下面 5 步完成一个能写文章、能浏览内页、能上线的博客。教程统一使用 **`my-blog` 文件夹**和**「小林的笔记」站名**，你可以先照着做，跑通后再换成自己的名字。

## 从哪里开始？

| 你的情况 | 从这里开始 |
| --- | --- |
| 还没有 Hexo 博客 | [第 1 步：安装主题](/guide/getting-started) |
| 已有 Hexo 8 博客，准备换主题 | [安装页的“已有博客”说明](/guide/getting-started#existing-blog) |
| Morii 已能打开，想换自己的资料 | [第 2 步：修改资料](/guide/first-config) |
| 想直接看文件应该写成什么样 | [完整示例与修改对照](/examples/) |
| 已经完成接入，只想查某个开关 | [配置手册](/config/) |

## 只按这条顺序做

| 步骤 | 这一步做什么 | 完成时应该看到 |
| --- | --- | --- |
| **1. [安装主题](/guide/getting-started)** | 创建博客，安装并启用 Morii | 本地能打开 Morii 首页 |
| **2. [修改资料](/guide/first-config)** | 设置站名和作者，创建个人主题配置 | 首页显示「小林的笔记」，不再使用作者的社交和服务配置 |
| **3. [写第一篇文章](/guide/first-post)** | 放入一篇完整文章 | 首页出现文章，点击能阅读 |
| **4. [补齐页面和菜单](/guide/complete-site)** | 创建关于、分类、标签、即刻和友链页 | 7 个顶部入口逐一能打开 |
| **5. [发布上线](/guide/publishing)** | 选择一个平台发布 | 用正式网址打开自己的博客 |

做到第 4 步，你已经有一个可以继续写作的博客。音乐、电影、天气、评论等功能可以以后从[功能指南](/features/)逐个添加。

## 先记住两个文件

所有路径都从**自己的博客目录 `my-blog/`**开始：

```text
my-blog/
├── _config.yml          ← 博客是谁：标题、作者、网址、使用的主题
├── _config.morii.yml    ← 博客长什么样：头像、菜单、主题功能
├── package.json
└── source/
    ├── _posts/         ← 文章
    ├── _data/          ← 即刻、友链等页面的数据
    └── about/index.md  ← 一个普通页面
```

你不需要在主题的安装目录里填写个人资料。正在阅读的 VitePress 文档站也不是你的博客，不需要把它的 `site/` 文件夹复制到博客里。

## 怎么读代码示例？

每个操作先看“**在哪里改**”和“**怎么改**”。

- **终端命令**：在博客目录的终端里逐行运行，不要写进 YAML 文件。
- **完整文件**：新建指定文件后，可以复制整个代码块。
- **修改已有字段**：只修改对应的行，保留其他配置，不要在文件末尾重复添加同名字段。

例如“修改 `_config.yml` 中的 `title`”表示：

::: code-group
```yaml [修改前：已有字段]
title: Hexo
```
```yaml [修改后：替换这一行]
title: 小林的笔记
```
:::

每一页结尾都有检查方法。当前步骤确认成功后，再进入下一步。
