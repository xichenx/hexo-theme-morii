# 功能指南：一次添加一个功能

先完成[补齐页面和菜单](/guide/complete-site)，确认基础博客能正常浏览，再选择下面一个功能跟着做。每次完成后都先本地验证，方便定位问题。

| 想添加的内容 | 准备什么 | 教程 |
| --- | --- | --- |
| 关于页的技能、经历和兴趣 | 自己的介绍文字 | [常用页面](/features/pages) |
| 照片相册 | 照片、相册列表页、详情页、数据文件 | [相册与友链](/features/album-links) |
| 友情链接 | 朋友的网站地址，可选头像 | [相册与友链](/features/album-links) |
| 音乐馆 | 自有音频或可用歌单接口 | [音乐与电影](/features/media) |
| 电影院 | 视频播放地址和片单 | [音乐与电影](/features/media) |
| 社交链接、二维码 | 账号主页或二维码图片 | [搜索、社交与评论](/features/interaction) |
| 评论、留言板 | 自己可用的 Twikoo 后端 | [搜索、社交与评论](/features/interaction) |
| 朋友圈文章流 | 提供 JSON 数据的接口 | [相册与友链](/features/album-links) |

## 先分清：页面、数据、入口

以友链为例：

| 这部分 | 文件 | 负责什么 |
| --- | --- | --- |
| 页面 | `source/link/index.md` | 让 `/link/` 存在，并使用友链布局 |
| 数据 | `source/_data/link.yml` | 告诉主题要显示哪些网站 |
| 入口 | `_config.morii.yml` 中的 `menu` | 在顶部放一个能点进去的链接 |

只写菜单不会创建页面；只建页面也不会自动产生友链内容。完整示例见[第 4 步](/guide/complete-site)。

## 只是想调整外观？

改颜色、首页推荐、阅读工具或侧栏，不需要新建页面。去[配置手册](/config/)按想修改的区域查找。
