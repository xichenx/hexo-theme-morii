# 演示素材

- `morii-demo.mp4` 录制于 2026-11-23，展示 Morii `v1.1.0`。时长 44 秒，1280 × 720，H.264，含可选中文字幕和章节，无音频。
- `morii-demo-preview.gif` 循环播放前 5.5 秒，展示首页的手写字标动效。
- `morii.png` 是 800 × 500 的多设备宣传图，展示 Morii v1.1.1，用于中英文 README 和 Hexo 官方主题目录。

画面录自 `npm run build:demo` 生成的本地演示站，使用示例文章。音乐馆使用示例歌单和歌词，移动端并列展示浅色首页与深色分类页。

更新时保持文件名不变，重新采集当前版本页面并替换两个媒体文件，同步中英文 README 的版本说明，并核对 MP4 内的章节。演示覆盖首页、阅读设置、分类、归档、图片查看、音乐、搜索、深色模式和手机尺寸，只使用公开演示内容。

这些素材保存在源码仓库的 `docs/media/`，不加入主题运行资源和安装包。安装包中的 README 可通过“查看完整演示”或“下载 MP4”的 GitHub 链接访问视频。
